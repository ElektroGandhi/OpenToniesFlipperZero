# Sicherheit · Security

**Deutsch:** Bitte melde Sicherheitsprobleme nicht als öffentliches Issue, sondern über
[GitHub Security Advisories](https://github.com/ElektroGandhi/OpenToniesFlipperZero/security/advisories/new).
Unterstützt werden nur der aktuelle Stand von `main` und das neueste Release. Es ist ein
Freizeitprojekt, eine feste Antwortzeit gibt es deshalb nicht.

Besonders interessant sind die Bluetooth-Befehle der App: Ist Bluetooth im Setup eingeschaltet,
kann jedes gekoppelte Gerät Wiedergabe und Favoriten steuern.

**English:** Please don't report security issues as a public issue. Use
[GitHub Security Advisories](https://github.com/ElektroGandhi/OpenToniesFlipperZero/security/advisories/new)
instead. Only the current `main` and the latest release are supported. This is a hobby project, so
there is no guaranteed response time.

The app's Bluetooth commands are of particular interest: when Bluetooth is enabled in the setup,
any paired device can control playback and favorites.
